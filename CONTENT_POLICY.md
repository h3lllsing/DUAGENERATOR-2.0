# Content Policy

Guidelines for Islamic dua content in Dua Video Generator.

## Content Guidelines

### Permitted Content
- Quranic duas and supplications
- Hadith-based prayers
- Authentic Islamic invocations
- Translations in Urdu and English
- Arabic text with proper diacritics

### Prohibited Content
- Fabricated or weak hadith without attribution
- Non-Islamic religious content
- Politically sensitive material
- Content that promotes division
- Misattributed quotes

## Quality Standards

### Arabic Text
- Use verified Quranic sources
- Include diacritics (tashkeel) for pronunciation
- Validate against Uthmani script
- Test with native Arabic speakers

### Translations
- Urdu translations must be accurate
- Avoid literal word-for-word translations
- Maintain spiritual meaning
- Use commonly accepted translations

### Audio
- Clear Arabic pronunciation
- Appropriate voice selection (Hamed for Arabic, Asad for Urdu)
- Proper pacing and pauses
- Background silence for reflection

## Review Process

1. **Source Verification** — All duas must have authentic source
2. **Translation Check** — Urdu translation reviewed by qualified person
3. **Audio Quality** — Pronunciation verified
4. **Visual Review** — Text rendering and effects approved
5. **Final Approval** — Content creator signs off

## Version Control

- All content changes tracked in git
- Previous versions accessible via commit history
- Major changes require review
- Emergency fixes documented in CHANGELOG.md

## Compliance

- Follow Islamic scholarly consensus
- Respect sect-neutral interpretations
- Include source attribution where possible
- Maintain respectful presentation
