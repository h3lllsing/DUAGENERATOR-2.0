## 3. ROADMAP — 4 PHASES

### PHASE 0: Abhi Kerne Wale Kaam (Is Hafte)
1. ✅ Phone verification (ho gaya)
2. 10–15 aur videos Private upload karo — sab ledger mein track honge
3. Har video khud dekho: audio clear? text readable? thumbnail match?
4. YouTube Studio → Channel customization: banner, about section, contact email daalo
5. Handle @bushranasir1075 consistent hai — wahi har jagah use karo

### PHASE 1: Quality Gate (Week 2)
1. Best 3 videos chuno (apni pasand se)
2. Unhe **Public** karo — baqi Private rahein
3. Studio Analytics dekho: *Swiped Away %* aur *Average View Duration*
   - Target: >70% log poora dekhen (Shorts retention)
   - Agar retention kharab → format problem, quantity naye bharne se kuch nahi hoga
4. Rozana 1 video fixed time par publish karo (consistency > volume)

### PHASE 2: Anti-Repetitiveness Upgrade (Jab Aap Bolo — Build Required)
Yeh wo changes hain jo pipeline mein karne hongey (ABHI NAHI):
1. **Theme rotation enforcement** — dark theme max 30%; har category ko default visual assign (ocean=sleep, sunset=evening, emerald=rizq...)
2. **Voice pool badhao** — edge-tts ke 4-5 aur voices add (ar-SA, ur-PK variants) aur per-category mapping
3. **Intro/outro variation** — 3 alag hooks rotate
4. **Disclaimer line** auto-append in descriptions: *"Ye content ibadati maqsad se hai; hawala diya gaya hai"*

### PHASE 3: Growth Engine (Month 2)
1. 500 subs target pehle (fan funding unlock: Super Thanks etc.)
2. Community tab active karo (dua graphics polls)
3. Comments ka jawab do pehle 1 ghante mein (algorithm signal)
4. Playlists banao: Morning Duas / Evening Duas / Travel Duas
5. Cross-post: Instagram Reels + TikTok (same content, no penalty — apna content hai)

### PHASE 4: YPP Application (Jab Eligible)
1. 1,000 subs + 10M Shorts views/90d (ya watch-hours route)
2. AdSense link, tax info, 2-step ✅
3. Review se PEHLE khud audit: koi 2 videos random dekho — kya ye "mass-produced" lagti hain? Agar haan → Phase 2 pehle complete karo
